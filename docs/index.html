Pourquoi LocalAI ?

🏠

100% Local

Tout tourne sur votre machine. Aucune donnee n'est envoyee vers le cloud, les serveurs, ou n'importe ou.

🔐

Chiffrement AES-256

Toutes les conversations sont chiffrees avec AES-256-GCM cote client. Meme le serveur ne peut pas les lire.

🚫

Zero Telemetry

Pas de tracking, pas d'analytics, pas de compte. Aucune information n'est collectee, jamais.

🌱

Mode Eco

Reduisez la consommation d'energie avec des reponses courtes et des modeles legers optimises.

📱

Multi-appareils

Phone, PC, tablette - meme interface responsive. Accessible depuis tout votre reseau local.

🔓

Non Censure

Modeles non censures disponibles : Dolphin, Gemma Abliterated. Aucune restriction artificielle.

⚡

Rapide

Interface moderne et fluide, streaming en temps reel, reponses instantanees sur votre hardware.

🛠️

Open Source

Code 100% transparent et auditable. Contribuez, amelorez, adaptez a vos besoins.

Comment ca marche ?

1

Installe Docker

Telechargez Docker Desktop sur votre machine. C'est gratuit et open source.

2

Lancez le script

Un seul clic sur le script d'installation. Tout se configure automatiquement.

3

Installez un modele

Choisissez parmi des dizaines de modeles : Qwen, Gemma, Llama, Dolphin...

4

Discutez !

Ouvrez votre navigateur et parlez avec votre IA 100% locale et securisee.

Installation

🪟 Windows

scripts\install-windows.bat

🐧 Linux

chmod +x scripts/install-linux.sh
./scripts/install-linux.sh

🍎 Mac

chmod +x scripts/install-mac.sh
./scripts/install-mac.sh

🐳 Manuel

docker compose up -d
docker exec localai-ollama ollama pull qwen3:8b
